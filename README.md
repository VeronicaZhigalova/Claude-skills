# Claude Skills — Вероника

Скиллы и правила, по которым Claude работает как дизайнер премиальных сайтов с вау-эффектом.

- `skills/premium-wow-design/SKILL.md` — процесс работы
- `references/taste.md` — вкус, референсы, стоп-лист AI-слопа, чек-лист
- `references/glossary.md` — словарь: премиальность, вау-эффект, направления
- `references/brief-questions.md` — вопросы по проекту
- `references/balance-matrix.md` — как определить баланс «Премиальность / Вау»

Чтобы скилл подхватывался автоматически в Claude Code, скопируй папку `skills/premium-wow-design` в `~/.claude/skills/` или в `.claude/skills/` проекта.
