# Кинематографичный первый экран: продукт, фото, 3D, видео

Рецепт, отработанный на Ombra Milano (2026-10). Использовать, когда вау ≥ 35 и продукт — главный герой (парфюм, ювелирка, часы, алкоголь, косметика, гаджеты).

## 1. Продукт: фото, а не 3D-модель
- 3D-модель, собранная кодом (Three.js), выглядит как «рендер». Для реализма — **фотография** (генерация в Figma `gemini-3.1-flash-image` или фото клиента).
- Промпт продукта: форма + материал + свет + поверхность + фон + плёнка + запреты. Пример: «heavy faceted decanter of thick smoky glass, dark amber perfume, obsidian stopper, bronze collar, on rough black Nero Marquina marble, pitch-black background, one narrow warm beam from above, chiaroscuro, real glass imperfections, tiny bubbles, Kodak Portra 400, no logos/text».
- Гравировка/название на продукте: «delicately etched into the glass in small frosted serif capitals "NAME"» — генератор пишет короткие слова правильно, проверять кропом.
- Всегда 2 варианта формы → выбор клиента. Мужской стиль: тяжёлое гранёное стекло, камень, металл; без «пимпочек» (трубки) в жидкости — писать «no visible dip tube».
- Апскейл: `tools/upscale.py` (Real-ESRGAN x4) + зерно σ≈2.5–3.

## 2. «3D из фото» — карта глубины
- `tools/depth.py in.png out.png` (Depth-Anything-V2-Small, CPU ~10 с). Затем MaxFilter(5) + GaussianBlur(4), 384–360 px по ширине — хватает.
- WebGL-шейдер: `uv -= mouse * (depth - .55) * vec2(.03…045, .02…03)` — ближние поверхности сдвигаются сильнее, предмет «поворачивается» за курсором. Без мыши — медленный «поворотный столик» (sin).
- Слои поверх в том же шейдере: луч света за курсором (gauss), блик-софтбокс по стеклу каждые 7–8 с (диагональная полоса), «живая» жидкость (fbm-переливы по янтарной маске), зерно.
- Проявление из темноты по глубине: ближние грани первыми (`smoothstep` по `1-depth` и прогрессу).
- Текстуры: максимум 6 слотов (телефоны гарантируют 8); несколько сцен — перепривязывать текстуры к одним слотам.

## 3. Видео: короткий фильм → живой последний кадр
- Своей видеогенерации нет (нет GPU). Figma Weave — видеомодели только на платном тарифе. Рабочий путь: **Higgsfield → Video → Create Video (image-to-video), Kling 3.0 / Veo 3**, первый кадр = наше фото, 9:16, 1080p, 8–10 с. Промпт и кадр готовлю в `projects/<проект>/video/`.
- Не давать последний кадр другого масштаба — продукт «плывёт».
- **Разобрать видео по кадрам** (ffmpeg fps=6–8, tile) и сравнить с исходником. Брак (другая крышка, лишние предметы, склейки) не показывать: обрезать до момента, где сравнивать не с чем, переход замаскировать дымкой.
- Кодирование: H.264 (crf 24, faststart, без звука) + VP9 WebM (crf 36) + версии 540p для телефонов; выбор `canPlayType`. 5–8 с ≈ 0,5–0,9 МБ.
- `muted playsinline`, запуск по таймеру; `play()` отклонён → сразу живой кадр. Тестовый Chromium без H.264 — для проверки нужен WebM.
- В конце: последний кадр (ffmpeg `-ss` у конца) → апскейл + карта глубины → WebGL-сцена в той же раскладке, что и видео; плавная смена `opacity` .8–.9 с. Застывший дым «оживает» UV-искажением fbm-шумом в зоне над горлышком.

## 4. Хореография первого экрана (что понравилось Веронике)
1. Чёрный экран 0,6 с.
2. Название по буквам: каждая из blur 16px → резкость, шаг 0,35 с, 1,8 с на букву. **Без декоративных линий** — строже и дороже.
3. Лёгкий дым появляется и сгущается (шейдер fbm, тёплый в луче), под ним стартует видео.
4. Дымка **редеет равномерно** 3,5 с и уходит вверх — не дырами (пятна выглядят дёшево).
5. Меню и кнопка проявляются после того, как продукт виден.
6. Финал живёт бесконечно: поворот, свет, блик, дым.

## 5. Что Вероника отвергла (не повторять)
- 3D-модель кодом вместо фото продукта.
- Полноэкранный «пролёт» сквозь ингредиенты как в рекламе на TikTok — «непонятное видео».
- Ингредиенты, летающие по орбите вокруг продукта — «не премиально».
- Блок, где «меняется только цвет жидкости».
- Видимые несовпадения в сгенерированном видео.
- Подчёркивание-«лезвие» под названием в мужском стиле.
