# Бесплатные шрифты (только бесплатные, платные не используем)

Перед использованием открыть страницу шрифта и проверить лицензию (OFL / free commercial). Записать лицензию в project-log.

## Источники
| Источник | Лицензия | Сильная сторона |
|---|---|---|
| Google Fonts / Fontsource | OFL | база, веб-хостинг |
| Fontshare (Indian Type Foundry) | ITF Free Font License (коммерция OK; нельзя перепродавать/модифицировать) или OFL — смотреть у каждого | премиальные гротески: Satoshi, General Sans, Clash Display, Cabinet Grotesk, Switzer, Erode, Gambetta, Zodiak, Sentient, Boska, Supreme, Panchang |
| Velvetyne (VTF) | OFL, просят указать автора | экспериментальные display: Ouroboros, Basteleur, Mess, Sligoil, Karrik, Terminal Grotesque |
| Collletttivo | OFL-подобная, можно коммерцию и модификацию | итальянский авангард: Mazius, Ribes, Necto Mono, Apoc… |
| Uncut.wtf | у каждого своя — проверять | каталог контемпорари гротесков и display |
| Open Foundry | OFL | кураторский отбор, хорошие страницы-образцы |
| Use & Modify | фильтр по лицензиям | редкие open-source шрифты |
| The League of Moveable Type | OFL | League Gothic, Ostrich, Orbitron |
| Font Library (fontlibrary.org) | OFL/GPL | архив open-source |
| Tunera, Production Type free, Pangram Pangram (только personal!) | Pangram free = НЕ для коммерции → не используем | |

## Правила
- Главный шрифт не повторяется между проектами (сверка с project-log.md).
- Пара подбирается под бизнес, не «моя привычная»: сначала 3 кандидата из разных источников, сравнительный скриншот, потом выбор.
- Если шрифт не на Google Fonts — подключаем через @font-face с локальными woff2 (в превью-артефакт файлы копируются).
