# Reference map: Veronika's full list and what to take from each

**The main rule:** the site sells first, beauty comes second. A reference is a tool, not a goal. Every borrowed device has to answer the client's request: more bookings, orders, enrolments. Our wow is minimal: one signature move, tied to the main value.

## How to work on every project
1. From the brief, write down the business goal and the action we sell (book, order, enrol).
2. Go through the page **section by section** (the table below). For each section, open its sources and find 3–5 examples **from the same or a neighbouring niche**, plus 1–2 from a completely different niche, for a fresh move.
3. **Don't copy, combine:** take one principle from each example (structure, rhythm, a move) and build our own version for this business.
4. Check against `project-log.md`: the section layout, type, palette and signature move must not repeat earlier projects.
5. In the brief, keep a "References used" table: section → source and example → what we took → which business goal it serves.

## Motion budget (strict)
- One signature move per site, tied to the main value.
- Micro-motion on buttons and states: calm and the same everywhere.
- Everything else stays still. No text animating in every block, no parallax "because it's pretty".
- Before any animation: "what does the visitor understand or do faster because of it?" No answer means no animation.
- Check with `tools/feel-check.js`.
