# Дизайн-системы полных сайтов Vistora (2026-10)

Figma: https://www.figma.com/design/Cc4CPMe2dcfGsX6PGYLBbo — страница «Full sites» (12 сайтов: все кадры по порядку + ч/б вайрфреймы + десктоп/мобайл), «More references» (15 пар + Reels), «Projects» (32 пары). Палитры извлечены из реальных экранов.

## Общая система (повторяется во всех)
- **Структура страницы**: hero-рамка с выемками → блок «о продукте» (2 колонки: текст + фото) → сетка карточек товаров/фич → полоса доверия (цифры, отзывы, портреты) → крупный CTA → подвал с гигантским словом-логотипом.
- **Мобайл**: та же последовательность одной колонкой; hero-заголовок остаётся огромным, карточки 1 в ряд, меню — пилюля сверху.
- **Сетка**: 12 колонок, поля 24–32 px внутри рамки, зазор 12–16 px. Карточки радиус 16–24, кнопки — пилюли или круги.
- **Типографика**: 1 дисплейный шрифт с характером + нейтральный гротеск для UI (12–14 px, серый).
- **Вайрфрейм-подача**: каждую страницу сначала строят в ч/б блоках (#2B2B2B карточки, #D9D9D9 строки, иконка «картинка» в плейсхолдере) — это и есть их «ч/б версия».

## Как использовать
1. На этапе направлений предлагать одну из систем как основу, адаптируя под бренд клиента (не копировать тексты, лого, фото).
2. Делать ч/б вайрфрейм страницы до цвета — показывать клиенту как первый шаг.
3. Всегда делать десктоп и мобайл парой.
