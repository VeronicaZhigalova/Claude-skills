# Рабочие правила Вероники

## 1. Шрифты
- Только бесплатные: Google Fonts, Fontshare, Velvetyne, Collletttivo, Pangram Pangram (free), Open Foundry, Uncut.wtf и др.
- Перед использованием проверить лицензию (разрешено коммерческое использование) и поддержку нужного языка.
- Бесплатный ≠ банальный: избегать «дефолтных» (Inter, Roboto, Open Sans, Montserrat, Poppins) без явной причины.

## 2. Изображения — два сценария
**A. Клиент дал материалы** → работаем с ними: кроп, единая обработка, арт-дирекшн вокруг них.

**B. Материалов нет** → я сам предлагаю визуальную концепцию **словами**:
- что изображено в каждом ключевом кадре (объект, свет, ракурс, фон, настроение, палитра);
- зачем этот кадр бизнесу.
Дальше по запросу Вероники:
1. генерирую изображения по описанию;
2. если не устроило — Вероника присылает свои фото, и я делаю ту же идею на их основе;
3. либо Вероника описывает свою идею/присылает документы клиента — работаю от них.
Ничего не генерирую без просьбы. Концепция всегда следует бизнес-идее и задуманному motion.

## 3. Формат работы
1. **Браузер (HTML/CSS)**: вместе находим направление, концепцию и первый экран. Показываю в браузере, правим, пока Вероника не подтвердит.
2. **Figma**: после подтверждения переносим концепцию в Figma и продолжаем там — клиент смотрит Figma, Вероника даёт правки по макету.

## 4. Язык сайтов
- По умолчанию **английский** (иностранные клиенты): тексты, шрифты, копирайт — на английском, живым нативным языком без шаблонных фраз.
- Русский — только если Вероника явно скажет. Тогда проверять кириллицу в шрифтах.
- Общение с Вероникой — по-русски.

## 5. Публикация
- **Никогда не публиковать сайт самостоятельно** (никаких деплоев, Netlify, Vercel и т.п.).
- Если Вероника спросит, как выложить сайт — только рассказать о способах; хостинг она выбирает сама.

## 6. Качество изображений
- Генерация: Figma (gemini-3.1-flash-image, ~1376px). Оригиналы скачивать из Figma напрямую (сеть Full).
- 4K: локальный AI-апскейлер Real-ESRGAN x4plus (torch CPU + spandrel, веса с GitHub releases), тайлами; ~4 мин на кадр 1376px. После апскейла вернуть лёгкое плёночное зерно (σ≈3), иначе кожа «пластиковая». Установка: `pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu && pip install spandrel`.
- Убрать лишнее с фото (например, нарисованный пар) — заливкой по соседним столбцам/строкам + зерно, проверять кропом.
- Каждый кадр проверять на артефакты ИИ: пальцы, суставы, логотипы, надписи, «грязные» стены.

## 7. Цепочка изображений и видео
1. Я генерирую фото (Figma) → Вероника смотрит.
2. Не устроило → увеличиваю до 4K (Lanczos) → смотрит.
3. Не устроило → Вероника сама генерирует в Higgsfield (фото/видео) или ищет в Pinterest/интернете.

Для каждого ключевого экрана я **сам решаю и объясняю**, что лучше: фото или видео (и почему), а затем даю:
- **Промпт для Higgsfield «с первого раза»** (генерации платные): на английском, всё в одном промпте — сюжет, действие по секундам, камера, свет, палитра, плёнка, длительность, формат, зацикленность, чего избегать. Если есть наше фото — режим image-to-video с ним как первым кадром.
- **Запросы для поиска** (Pinterest и др.): 5–8 точных фраз на английском + на что смотреть при выборе.

## 8. Финальная сборка изображений
- На сайт — WebP (q80) с width/height у <img>; оригиналы PNG храним в img/*-original.png.

## Видео и «живые» заставки (2026-10)
- Своей видеогенерации у Claude нет: в облаке нет видеокарты, модели вроде Wan/LTX на процессоре не работают.
- По умолчанию заставка — **код**: WebGL-шейдер по фото + карта глубины (`tools/depth.py`), дым/пыль/посадка/свет — шейдером. Быстро, бесплатно, интерактивно (пример: Ombra «Ritual»).
- Настоящее видео (открывание пробки, течение жидкости): Figma Weave подключён, но видеомодели в нём только на платном тарифе. Пока — Higgsfield (Kling 3.0 / Veo 3, image-to-video): я готовлю первый кадр и промпт в `projects/<проект>/video/`, Вероника генерирует. Последний кадр задавать, только если флакон в нём того же масштаба и положения, иначе модель «плывёт».
- Апскейл: `tools/upscale.py in.png out.png <ширина>` (нужен RealESRGAN_x4plus.pth + spandrel).


## Материалы проекта: кто что делает (Вероника, 2026-10)
- Видео продукта (повороты, фильмы) — Вероника генерирует в Higgsfield по моему промпту и стартовому кадру (`projects/<проект>/video/PROMPT.md`). Я встраиваю, режу, кодирую.
- Фото, логотип, слоганы, тексты клиента — присылает Вероника. Я их не переписываю без нужды, только адаптирую под сайт.
- Сама генерирую (Figma AI) только недостающее: фоны, текстуры, атмосферу, заглушки. Полностью с нуля (нейминг, слоган, тон, фото) — только когда клиент начинает бизнес с нуля и материалов нет.
