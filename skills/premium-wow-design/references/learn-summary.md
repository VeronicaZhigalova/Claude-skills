# Короткая выжимка обучения 22.10 (читать перед каждым проектом, вместе с taste.md и human-made.md)
Подробности: learn-typography-spacing.md, learn-color-imagery.md, learn-motion.md, learn-business-conversion.md, learn-sources-map.md.

## Бизнес
1. Бриф → одно главное действие → оффер «польза + для кого + лёгкий старт + снятие риска».
2. Каждый блок отвечает на вопрос посетителя: что это, почему вам, можно ли доверять, сколько стоит, что будет дальше, что делать сейчас.
3. Hero: ценность, доказательство рядом, одна кнопка «глагол + выгода», под ней снятие риска. Срочность только честная (реальные места, реальный дедлайн доставки).
4. Формы: 6–8 полей максимум, сначала ближайшие слоты, гостевая запись, sticky-CTA на мобайле.
5. Тексты: конкретика, слова клиентов, тест «и что?», никаких ИИ-клише; читать вслух.

## Типографика и отступы
6. 2 семейства, 3–4 начертания, 3 стиля текста на странице. Курсив запрещён.
7. Текст 16–18px, строка 45–75 знаков, межстрочный 1.5–1.7; заголовки 1.0–1.15, дисплей 0.9–1.0 с трекингом −0.01…−0.03em; капс +0.08…+0.14em.
8. Отступ над заголовком ≈ в 2 раза больше, чем под ним; секции 96–160px десктоп / 56–80px мобайл; тап-зоны ≥ 44px; поля на мобайле 16–24px.
9. Не брать затёртые пары (Playfair+Inter, Montserrat+Open Sans, Poppins везде).

## Цвет и фото
10. Палитра снимается с фото бренда, в OKLCH; акцент 2–5% площади; текст не чистый чёрный; мягкость — фонами, а не бледным текстом (контраст ≥ 4.5:1).
11. Все фото: одна локация, один свет, один цветокор; генерация «как съёмка» (объектив, свет, несовершенства); апскейл до 3840, потом цветокор.
12. Hero-картинка без lazy, с fetchpriority="high", в HTML; ≤ 250 КБ в AVIF/WebP. Видео только если есть хорошая съёмка, ≤ 3–8 МБ, с постером.

## Движение
13. Один главный жест в hero (1.2–1.6 с), ниже движения меньше; появление при скролле один раз, 600–900 мс, ease-out, без ease-in.
14. Анимировать только transform/opacity; никакого 3D-наклона, параллакса на всём, перехвата скролла, «туда-обратно» при скролле.
15. prefers-reduced-motion обязателен; на слабых устройствах отключать WebGL.

## Где брать идеи
16. Кит Вероники (prototype-kit.md) → figmaformotion (hero-формула) → horizonx (интерактивные hero) → lenis showcase (скролл) → godly/minimal.gallery (спокойный люкс) → mobbin/refero (флоу записи) → pricingpages/cta.gallery/footer.design. Таблица «задача → куда идти» в learn-sources-map.md.
