# Короткая выжимка обучения 22.10 (читать перед каждым проектом, вместе с taste.md и human-made.md)
Подробности: learn-typography-spacing.md, learn-color-imagery.md, learn-motion.md, learn-business-conversion.md, learn-sources-map.md.

## Бизнес
1. Бриф → одно главное действие → оффер «польза + для кого + лёгкий старт + снятие риска».
2. Каждый блок отвечает на вопрос посетителя: что это, почему вам, можно ли доверять, сколько стоит, что будет дальше, что делать сейчас.
3. Hero: ценность, доказательство рядом, одна кнопка «глагол + выгода», под ней снятие риска. Срочность только честная (реальные места, реальный дедлайн доставки).
4. Формы: 6–8 полей максимум, сначала ближайшие слоты, гостевая запись, sticky-CTA на мобайле.
5. Тексты: конкретика, слова клиентов, тест «и что?», никаких ИИ-клише; читать вслух.

## Типографика и отступы
6. 2 семейства, 3–4 начертания, 3 стиля текста на странице. Курсив запрещён.
7. Текст 16–18px, строка 45–75 знаков, межстрочный 1.5–1.7; заголовки 1.0–1.15, дисплей 0.9–1.0 с трекингом −0.01…−0.03em; капс +0.08…+0.14em.
8. Отступ над заголовком ≈ в 2 раза больше, чем под ним; секции 96–160px десктоп / 56–80px мобайл; тап-зоны ≥ 44px; поля на мобайле 16–24px.
9. Не брать затёртые пары (Playfair+Inter, Montserrat+Open Sans, Poppins везде).

## Цвет и фото
10. Палитра снимается с фото бренда, в OKLCH; акцент 2–5% площади; текст не чистый чёрный; мягкость — фонами, а не бледным текстом (контраст ≥ 4.5:1).
11. Все фото: одна локация, один свет, один цветокор; генерация «как съёмка» (объектив, свет, несовершенства); апскейл до 3840, потом цветокор.
12. Hero-картинка без lazy, с fetchpriority="high", в HTML; ≤ 250 КБ в AVIF/WebP. Видео только если есть хорошая съёмка, ≤ 3–8 МБ, с постером.

## Движение
13. Один главный жест в hero (1.2–1.6 с), ниже движения меньше; появление при скролле один раз, 600–900 мс, ease-out, без ease-in.
14. Анимировать только transform/opacity; никакого 3D-наклона, параллакса на всём, перехвата скролла, «туда-обратно» при скролле.
15. prefers-reduced-motion обязателен; на слабых устройствах отключать WebGL.

## Где брать идеи
16. Кит Вероники (prototype-kit.md) → figmaformotion (hero-формула) → horizonx (интерактивные hero) → lenis showcase (скролл) → godly/minimal.gallery (спокойный люкс) → mobbin/refero (флоу записи) → pricingpages/cta.gallery/footer.design. Таблица «задача → куда идти» в learn-sources-map.md.

## Добавлено после второго захода (22.10, страницы реально прочитаны, URL в файлах)
17. Процесс студий (learn-process.md): стратегия и одна концептуальная метафора → мудборд или style tiles (3 «личности» по 3–4 прилагательных, клиент выбирает одну) → вёрстка на реальном тексте → фирменный интерактив, который несёт навигацию или историю → ревью раз в неделю → QA по чек-листу (320/375/1440, отправить формы, noindex, 301, аналитика) → запуск под присмотром 48–72 ч.
18. Кейс в портфолио: Задача → Подход (пары «проблема → решение») → Результат (метрика или цитата) → Выводы; плюс видео сигнатурного момента.
19. Насмотренность (learn-studios-deconstructed.md, learn-niche-playbook.md, 70+ сайтов замерены вживую):
    - тихий люкс: тёплый off-white (#F3EEE7), графитовый текст (#313131), светлая засечка 300–400, кнопки без скругления, один акцент;
    - велнес и бутик-пилатес: льняной фон, коричневый текст, кнопка-пилюля «Book a class» в шапке;
    - фитнес и энергия: узкий гротеск капсом, плотный интерлиньяж 0.8–0.9, энергия от масштаба, а не от цвета;
    - цветы: люкс — разреженный капс, белый фон, шоколадная кнопка; дружелюбные — газетная засечка, сезонные плашки;
    - клиники нового типа ушли от больничного голубого к тёплым засечкам и шалфею; юристы — от «синий + Times»;
    - текст почти никогда не чисто чёрный, фон в тёплых нишах почти никогда не чисто белый.
20. Логотип (learn-logo-brand.md): символ только при веской причине (Хавив); тесты 16×16, один цвет, инверсия; показывать клиенту 3 близких концепта в контексте, не на белом листе.
21. UX-основа (learn-curriculum.md, learn-research-a11y.md): 10 эвристик Нильсена, 30 законов UX, гештальт; тест на 5 людях находит ~85% проблем, лучше 3 раунда по 5; WCAG 2.2 AA: контраст 4.5:1, видимый фокус, цели ≥ 24×24, пауза для движения дольше 5 с.
22. Figma (learn-figma.md): auto layout (Hug только фрейму, Fill только детям), варианты для Style/Size/State, токены в три слоя primitive → semantic → component, файл на проект, страница для разработчиков.

## Третий заход (22.10, пробелы закрыты)
23. Вёрстка и SEO (learn-frontend-seo.md): Core Web Vitals — LCP ≤ 2.5 с, INP ≤ 200 мс, CLS ≤ 0.1; hero-картинка без lazy, fetchpriority="high", width/height у всех img; clamp() в rem+vw; шрифты WOFF2 + size-adjust; у каждой страницы свои title/description, Open Graph (4 тега), JSON-LD LocalBusiness.
24. 3D (learn-3d-webgl.md): один 3D-момент на страницу и только со смыслом; один эффект — OGL/чистый WebGL, продукт — three.js, сцена от дизайнера — Spline, просмотр модели — model-viewer; glTF + KTX2, DPR ≤ 1.5 на мобайле, рендер по требованию, пауза вне экрана, постер-фолбэк.
25. Магазин (learn-ecommerce.md): над сгибом фото, название, цена, рейтинг, варианты, кнопка; дата доставки, а не срок, и время отсечки рядом с кнопкой; допродажи отдельным шагом после «добавить»; гостевое оформление, 7–8 полей, одно поле «Full name»; подарок: адрес получателя, скрытая цена, открытка; липкая кнопка с ценой на мобайле.
