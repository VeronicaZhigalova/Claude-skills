# Самопроверка «глазами жюри Awwwards» (перед каждой сдачей)

Оценить по 10-балльной шкале, честно. Ниже 8 по любому пункту — доработать до показа Веронике.

| Критерий (вес) | Вопрос |
|---|---|
| Дизайн (40%) | Узнаётся ли бизнес по шрифту, цвету и первому кадру? Есть ли один смелый ход, а вокруг тишина? |
| Удобство (30%) | Понятно ли за 5 секунд, что это, для кого и что нажать? Удобно ли с телефона? |
| Креативность (20%) | Есть ли приём, которого не было в прошлых проектах (`project-log.md`)? Есть ли момент «как это сделано?!» |
| Контент (10%) | Тексты живые, конкретные, без шаблонных фраз? Фото в одном стиле, без артефактов ИИ? |

## Тест «это сделал ИИ?»
Если хотя бы один пункт «да» — переделать:
- шрифт, палитру или раскладку можно перенести на другой бизнес без потерь;
- всё выровнено по центру и симметрично;
- секции идут одинаковым ритмом «заголовок — текст — 3 карточки»;
- каждый блок появляется одинаковым fade-in;
- в тексте есть «Elevate», «Unlock», «Seamless», «Discover the power»;
- на фото лишние пальцы, логотипы, надписи-каракули, пластиковая кожа.

В ответе Веронике коротко показать оценки и что исправлено.
