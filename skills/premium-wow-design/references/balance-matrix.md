# Баланс «Премиальность / Вау»

Цель — гармоничное решение под бизнес, а не механическое смешение стилей. Итог всегда показываю в виде **«Премиальность X / Вау Y»** с обоснованием.

## Шаг 1. Базовое соотношение по типу задачи
| Тип сайта | Старт | Почему |
|---|---|---|
| Интернет-магазин, каталог, сервис с частыми задачами | 85 / 15 | скорость и ясность важнее эффектов |
| Медицина, юристы, финансы, недвижимость | 80 / 20 | доверие и спокойствие |
| Косметика, парфюм, ювелирка, отели, рестораны | 70 / 30 | эмоция и атмосфера продают |
| Мода, архитектура, дизайн-студии, фотографы | 55 / 45 | сайт — часть портфолио |
| Запуск продукта, промо, мероприятие, digital-агентство | 40 / 60 | задача — запомниться |

## Шаг 2. Сдвиги по ответам брифа
| Ответ | Сдвиг |
|---|---|
| Приоритет — быстрое выполнение задач | +10 к премиальности |
| Приоритет — эмоциональная презентация | +10 к вау |
| Премиальность «тихая» | +5–10 к премиальности |
| Премиальность «смелая/экспериментальная» | +5–10 к вау |
| Интенсивность «деликатная» | вау не больше 30 |
| Интенсивность «погружение» | вау не меньше 40 |
| Аудитория в основном с телефона | −10 к вау (тяжёлые эффекты урезаются) |
| Нет качественных фото/видео/3D-ассетов | вау через типографику и композицию, не через картинку |
| Сайт обновляет сам клиент | упростить motion и сетку |

## Шаг 3. Выбор источника вау
| Бизнес | Подходит | Не подходит |
|---|---|---|
| Косметика, парфюм | cinematic фото, мягкий motion, editorial | тяжёлое 3D, агрессивные эффекты |
| Спорт | динамичная типографика, видео, быстрый motion | тихая роскошь без движения |
| Архитектура | экспериментальная сетка, крупная типографика, фото | яркие цвета |
| Tech / AI / продукт | 3D, immersive, motion | старомодная антиква |
| Медицина, финансы | композиция, фото, деликатный motion | 3D ради 3D, резкие эффекты |
| E-commerce | вау только на главной и в промо-блоках; каталог чистый | анимации, мешающие покупке |

## Шаг 4. Перевод в решения
| Вау | Что это значит на практике |
|---|---|
| 10–20 | 1 сильный первый экран (фото или типографика), мягкие fade/reveal, hover-детали |
| 25–40 | + сценарий скролла: раскрытие секций, параллакс фото, анимация заголовков |
| 45–60 | + пиннинг секций, горизонтальный скролл, морфинг, видео, экспериментальная сетка |
| 60+ | + 3D/WebGL, интерактивные сцены, погружение (обязателен лёгкий фолбэк и мобильная версия) |

## Когда я говорю «нет»
Если просят много вау, а бизнесу это вредит (например, магазин, где важно быстро найти товар) — объясняю почему и предлагаю перенести вау туда, где оно не мешает: первый экран, промо-блок, страница бренда.
