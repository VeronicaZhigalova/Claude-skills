# Бриф: кафе «Matcha» (учебный проект, клиент — Вероника)

## Часть 1
- Бизнес: кафе матча (точка есть, на вынос) + новый онлайн-магазин с доставкой на дом.
- Отличие: конструктор своего напитка (молоко → фрукт/варенье → матча), высокое качество матчи, натуральные продукты, «прикольные» фирменные стаканчики.
- Цель сайта: имидж + дистанционные заказы.
- Одно действие: собрать свою матчу и оформить доставку.
- Аудитория: все возрасты, любители матчи; приходят за эмоцией — «я сам автор вкуса сегодня», натурально, по выгодной цене.
- Устройства: в основном телефон (mobile-first), десктоп тоже полноценный.
- Бренд в словах: здоровое, натуральное, современное, интересная подача в стаканчиках.
- Активы: ничего нет. Цвета ассоциативно зелёный/белый/розовый. Название «Matcha». Логотип — можно предложить новый.

## Часть 2
- Настроение: тихая роскошь + смелый модный современный бренд (баланс).
- Вау: 1) сочные фото/видео (льётся молоко, слои смешиваются), 2) конструктор — стакан наполняется слоями на экране. Доп.: смелая типографика, возможно 3D-стакан.
- Интенсивность: не ответила → предлагаю «средне-сильно»: сильный первый экран и конструктор, остальное деликатно.
- Фото/видео нет → генерация (Figma / Higgsfield), затем оживление.
- Доставка через Wolt / Uber Eats, бесплатно от €20, по всей стране. Без подписки.
- Цена: базовая матча €10 (матча + молоко + вкус), экстра — доплата.
- Референсы: нет → конкурентный анализ + наш эталон (HorizonX, дизайн-системы).
