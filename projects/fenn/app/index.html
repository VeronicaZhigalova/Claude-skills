Fenn design system

Every pet owns a colour, so the app feels like their card, not the clinic's. The clinic side keeps the same palette on a hard grid with mono labels, like hospital signage. One set of tokens runs both.

Colour

Pet colours are for identity only. Status has its own colours that never change: amber means "soon", red means "act now", teal means "all good".

Type

Big Shoulders Display, uppercase, for names, numbers and headings. Work Sans for everything people read. Space Mono only for labels and times.
