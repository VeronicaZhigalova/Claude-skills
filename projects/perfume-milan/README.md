# Ombra Milano — концепт парфюмерного дома (2026-10)

Нишевый парфюмерный дом в Брере, Милан. Драматичная роскошь, тёмная тема, мужской стиль. Премиальность 60 / Вау 40.

- Превью: https://claude.ai/artifact/99XMA7LkZTE7ia57oWHN6Q
- Код: `index.html` (превью), `build.py` → `dist/` (готовый сайт для хостинга)
- Цель: продать набор из 7 пробников (€45, засчитывается в флакон), затем флакон; консультация — второй путь.
- Первый экран: OMBRA по буквам → дымка → фильм Higgsfield (с 2,55 с) → живой последний кадр (WebGL, карта глубины).
- Разделы: манифест, коллекция (фото за курсором), набор, как это сделано (pin I–IV), консультация (форма), бутик, подвал.
- Аудит (Lighthouse, dist): десктоп 99/100/100/100, телефон 80/100/100/100 (LCP 4.8 с — по замыслу заставки), CLS 0.004–0.014, 320–1920 без горизонтального скролла, без ошибок консоли.
- Не входит: реальная оплата и запись (Shopify/Stripe и система бронирования), хостинг, проверка на iPhone/Safari.
